# Project Overview

Portfolio website for Alvaro Llamojha - DevOps & Observability Engineer.

## Tech Stack
- React 19
- TypeScript
- Vite

## Structure
- `App.tsx` - Main application component
- `components/` - React components
- `assets/` - Static assets

## Development
```bash
npm install
npm run dev
```

## Environment
Set `GEMINI_API_KEY` in `.env.local` for AI features.
